# Bateria

Projeto web para exibir a interface de bateria e executar o servidor auxiliar
em múltiplas portas.

## Arquivos

- `index.html`: interface do projeto.
- `servidor_multiplas_portas.py`: servidor auxiliar em Python.

## Como executar

Abra `index.html` diretamente no navegador ou inicie um servidor local na
pasta:

```bash
python servidor_multiplas_portas.py
```

## Estado
